Step 5 · reaction_human.py · my extension

People react before they correct

In the paper, the person steps in at random, 20% of the time. Real people don't. When a robot starts doing the wrong thing, they frown, lean in, say "hm?", and only then grab control. My PhD work detects exactly these reactions (HEV and PDV). This step asks: can the robot use them to ask earlier and less often, without losing the coverage guarantee?

1

The gap in the paper

The robot has to make mistakes before its margin grows.

IQT grows the margin only after it sees misses. Right after the expert changes their mind, the margin is still narrow, so the robot rarely asks; it learns of the change only from the 20% random interventions. Meanwhile the person watches the robot head the wrong way.

But that watching person is giving off information the whole time. Their face and voice change before they act. That is a free, early, but weak signal: it says "something seems wrong", not "here is the right action".

HEV: Human Expectation Violation

The person reacts to something unexpected the robot did: surprise, a frown, a sharp look. Here: the robot heading away from where the person wants the cup.

PDV: Personal Deviation

Each person reacts differently. Some are very expressive, some barely move. So a reaction is judged against this person's normal level, learned in the first minutes.

Expressive1.2Reacts clearly, early.

Reserved0.3Barely reacts; the robot must rely on asking.

PDV in practice: during episode 1 (when nothing is wrong) the robot records the person's reaction level and its spread. Later, a reaction counts only if it is well above that person's own normal (for example, 3 spreads above their average). This stops an expressive person from triggering questions all the time, and lets a reserved person's small reactions still count.

4

How the robot uses reactions

Main idea: a reaction raises the chance of asking right now.

P(ask) = 1 − (1 − sigmoid(β · (u − τ))) · (1 − ρ · flag_t)

flag_t = 1 if this person's reaction is well above their own normal (PDV), else 0
ρ      = how much the robot trusts a reaction (e.g. 0.8)

Worked example

just after the shift: margin still narrow, u = 0.03  →  sigmoid(100 · (0.03 − 0.06)) = 0.05
no reaction:   P(ask) = 0.05
reaction seen: P(ask) = 1 − (1 − 0.05)(1 − 0.8) = 1 − 0.95 · 0.2 = 0.81

So the robot asks right when the person looks surprised, gets the expert's action, sees a miss, and IQT widens the margin straight away, steps earlier than waiting for a random intervention.

A second, riskier idea for later: count a reaction as a "probable miss" even when no action is given. That would update the margin without any feedback at all, but it breaks the guarantee (the robot would be guessing err). I will try it only as a side experiment and label it clearly.

5

Why the guarantee still holds

IQT only needs to know p: the chance that feedback is seen at this step.

The paper's guarantee (Proposition 1) holds for any p, as long as the robot knows the p it used. The robot sees the reaction itself, so it knows exactly how likely it was to ask. So:

p_t = c + P(ask) − c · P(ask)          with the new P(ask) above: still known, so IQT is still valid

There is one honest catch. In the paper, the person's own stepping-in rate c is a known constant. A realistic person steps in more when the robot is wrong, so the true c is not known. I will test what happens when the robot assumes c = 0.2 but the person behaves realistically, and whether the reaction signal can be used to estimate the person's real stepping-in chance.

The question in one line: do people's reactions let the robot notice an expert shift sooner, with fewer explicit questions, while keeping the margin honest? This links Dr Zhao's "when should a robot ask" with my "what do people's reactions tell a robot".
