Interactive

Be the planner, let the checker judge

Move the blocks by clicking, or type a plan, then press Check the plan. The checker writes the same action-by-action explanation that the model was trained on. Try a wrong plan too, and switch to Mystery names to see how hard the logic is without familiar words.

Things to try

    
    
      
  • Break the rules on purpose. In the first problem, type (stack a c) alone and check it. The checker names the missing fact, (holding a). A Phase 1 "broken plan" example looks exactly like this.
    • 
      
  • Stop early. Check only (pick-up a). Every step is legal, but the checker reports that the goal is not reached.
    • 
      
  • Switch to Mystery. The same problem now reads (attack a) (overcome a c). You can still solve it by reading the rules, which is exactly what the model has to learn.
    • 
      
  • Try 5 blocks. There are 866 possible states. Notice how quickly it gets hard to keep the whole state in your head; small language models struggle at the same point.
    • 
    

    
The shortest-plan button searches every reachable state (breadth-first search). Training data used the A* planner, which finds the same shortest plans faster.
